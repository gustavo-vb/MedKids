# Software para auxílio de atendimento à crianças
`CIÊNCIA DA COMPUTAÇÃO`

`TRABALHO ACADÊMICO INTEGRADO II`

`1º SEMESTRE DE 2026`

O nosso projeto tem como objetivo tornar a experiência de exames médicos menos assustadora para crianças, especialmente crianças pequenas. Por meio de um site interativo, buscamos explicar de forma simples, visual e divertida como tipos diferentes de exames são realizados, ajudando os pequenos a entenderem o que irá acontecer e assim, se sentirem mais seguros e confortáveis durante o atendimento.

No site desenvolvido, os exames serão explicados a partir de vídeos curtos explicativos e/ou mini-jogos educativos, permitindo que a criança aprenda de forma lúdica. O conteúdo será organizado em duas categorias principais: *exames laboratoriais*, como o exame de sangue, e *exames de imagem*, como raio-x, ressonância magnética e outros, facilitando a compreensão de cada procedimento.
